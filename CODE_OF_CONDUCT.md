# Code of Conduct

The ENTITY project is intended to support serious engineering collaboration around identity, authority, provenance, rights, and provider-independent infrastructure.

Contributors are expected to:

- communicate professionally and in good faith;
- critique implementations and evidence rather than attacking people;
- respect privacy and security boundaries;
- avoid publishing credentials, private user data, or exploit details that would create unnecessary risk;
- accurately distinguish implemented, tested, qualified, experimental, and proposed functionality.

Harassment, threats, discrimination, deliberate doxxing, and malicious disclosure of private security material are not acceptable.

Project maintainers may moderate contributions and participation to protect contributors, users, and the integrity of the project.
