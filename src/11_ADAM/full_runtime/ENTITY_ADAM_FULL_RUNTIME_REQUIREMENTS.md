# ENTITY / Full ADAM v1.0 Integration Requirements

ENTITY remains authoritative for identity, delegation, rights, policy, consent, contracts and sovereign portability. ADAM owns deterministic atomic information, exact evidence/reconstruction, reaction-governed state transitions, history and bounded ADAM runtime evidence. NIKI reasons over bounded projections only.

Protocol 1.0 is frozen and is not silently reinterpreted by this integration. Full ADAM semantics are introduced on the ENTITY 2.0 development line.

Authoritative ADAM commits require current ENTITY authorization evidence and fail closed when authorization cannot be verified. Exact evidence must remain reconstructable. Semantic transition claims remain linked to exact evidence. ADAM external certification gates remain separate from software integration qualification.
